Basics of CSS

Theory

CSS Introduction

Now that we have gained basic HTML skills, our website needs something more. Like a house without furniture, a cake without frosting, or a party without snacks, it feels incomplete, right? We need to add style to make our website beautiful and modern.
For styling, we use Cascading Style Sheets (CSS). CSS is a separate language with its own syntax. With CSS, you can control how your website looks and feels—from colors and fonts to layout and spacing.
There are three ways to use CSS with HTML: External Stylesheet, Internal CSS, and Inline CSS. The recommended approach is using an External Stylesheet, where you create a separate
.css
file to contain all your CSS rules and link it to your HTML file. CSS files are linked in the HTML's
<head>
tag. The
styles.css
file, when linked to the document, applies its styles to the content in the
<body>
.
<link rel="stylesheet" href="styles.css">
​

Element Type Selector

Elements like h1 and p can be used as selectors in CSS. These are called element type selectors — the most basic form of CSS selectors. When you define properties using these selectors, they apply to every instance of that element in your document.
h1 { color: blue; font-family: verdana; font-size: 300%; }
​

ID Selector

An ID selector is another type of selector that targets a specific element using its id attribute. It uses the # symbol—for example, #recipe selects element with id="recipe".
<p id="recipe">Hello World!</p>
​
#recipe { text-align: center; color: red; }
​

Class Selector

A class selector targets multiple elements that share the same
class
attribute. It uses the
.
symbol—for example,
.button
selects all elements with
class="button"
.
<div class="button">Button 1</div> <div class="button">Button 2</div>
​
.button { background-color: green; color: white; }
​
CSS selectors come in three main types, each with a distinct purpose. Element type selectors style all instances of a specific HTML element (like
<p>
or
<h1>
) throughout the page. Class selectors target multiple elements sharing the same class attribute, making it easy to apply consistent styles across different elements. ID selectors style just one unique element using its id attribute.
As we learned from the previous chapter, HTML is divided into two parts: head and body. The
<html>
element is the root, containing
<head>
and
<body>
as its children. The Head Section contains meta-information about the page (like the title, styles, and metadata). The Body Section contains the visible content on the page, such as headings, paragraphs, emphasized text, and images. If you change the style of the
<body>
tag, the style will cascade down to its child elements, but not upward to parent elements.

Formatting Text

One of the most important aspects of styling is text appearance. While HTML provides six heading options, you might want to make fonts bigger or change the font family itself. The default font for an
<h1>
tag (or any other HTML element) depends on the browser and operating system. Most modern browsers use default system fonts when no specific font is defined through CSS.
For example, common defaults for
<h1>
tags are:
Windows: Segoe UI.
macOS: San Francisco or Helvetica Neue.
Linux: DejaVu Sans, Ubuntu, or other system fonts.
Let’s begin with the font-family property. Use the
font-family
property to specify a font or list of fonts (known as a font stack) by name, as shown in these examples:
body { font-family: Arial; } var { font-family: Courier, monospace; } p { font-family: "Duru Sans", Verdana, sans-serif; }
​
Here are some important syntax requirements:
All font names, with the exception of generic font families, must be capitalized. For example, use Arial instead of arial.
Use commas to separate multiple font names, as shown in the second and third examples.
Notice that font names that contain a character space (such as Duru Sans in the third example) must appear within quotation marks.
When a browser cannot find a specified font (like Futura)—either because it's not installed on the user's computer or the web font fails to load—it falls back to its default font. CSS provides a fallback system through font stacks, which are lists of backup fonts. The browser works through this list until it finds an available font. For instance, in the font-family rule above, if Duru Sans isn't available, the browser tries Verdana, and if that's not found, it uses any available sans-serif font.
CSS also allows you to adjust various text properties including font size, weight, style, line height, decoration, letter spacing, and word spacing.
h1{ font-size: 96px; font-weight: bold; font-style: italic; line-height: 1.5; text-decoration: underline; letter-spacing: 1px; word-spacing: 5px; }
​

The units of measurement in CSS

CSS offers various units of measurement for controlling font sizes, element dimensions, margins, indents, and other layout properties. While some units are familiar (like inches and millimeters), others require more explanation—specifically absolute units, rem, em, and viewport units (vw/vh).
Absolute Units
Absolute units maintain fixed sizes regardless of screen size or resolution. They work best when you need specific, unchanging measurements. Common absolute units include:
px (pixels): The standard unit in CSS, representing one dot on a device's screen.
in (inches): Used mainly for print designs where exact physical measurements matter.
cm (centimeters) and mm (millimeters): Like inches, these units are more common in print styling than web design.
pt (points): A typography unit where 1 point equals 1/72 of an inch.
pc (picas): Equal to 12 points, primarily used in traditional print.
While absolute units are simple to understand, they lack the flexibility needed for responsive design.
Relative Units
Relative units are based on other measurements like parent element size, viewport dimensions, or font size. These units are essential for creating flexible, adaptable layouts.
em: Based on the parent element's font size. For example,
2em
means twice the parent's font size. Commonly used for typography and spacing.
rem (root em): Similar to
em
, but references the root element's font size (typically
<html>
). This provides better consistency across designs since it's independent of element hierarchy.
% (percentage): Defines dimensions relative to the parent element. Perfect for responsive widths and heights, allowing elements to adjust to their container size.
vw and vh (viewport width and height): Based on the browser window size. For example:
1vw
equals 1% of the viewport width.
1vh
equals 1% of the viewport height. These units excel in responsive designs, particularly for fullscreen elements.
vmin and vmax: Reference the viewport's smallest or largest dimension:
vmin
helps maintain consistent aspect ratios in responsive layouts.
vmax
ensures elements scale with the viewport's larger dimension.

Colors and Backgrounds

CSS offers two primary methods for specifying colors in stylesheets: color names and RGB values.

Color Names

The simplest way to specify a color is by using its name. However, you must use one of the color keywords predefined in the CSS specification. The original CSS1 and CSS2 specifications included 16 standard color names from HTML 4.01. CSS2.1 added "orange" for a total of 17 colors. CSS3 expanded this to include 140 more descriptive color names. This means we can now use creative names like "burlywood," "peachpuff," and "oldlace". To see all the extended colors, check for a more detailed view, visit learningwebdesign.com/colornames.html.
color: olive;
​

RGB Values

While color names are easy to use, they offer limited options. RGB values are the most common method for specifying colors, providing access to millions of possible color choices.
color: #ff0000;
​
We will not get into the theory of the RGB and where it’s coming from. But if you need to use RGB values, you can Google the value which you want. Or in IntelliJ you can pickup the color from sliders and selectors.
CSS lets you customize colors for various webpage elements. Here are some common examples:
Text Colors
Background Colors
Border Colors
Outline Colors

Margins

Margins control the spacing around elements on a web page. As the outermost part of the box model, they create space between an element's border and its surrounding elements. You can set margins using individual properties (
margin-top
,
margin-right
,
margin-bottom
,
margin-left
) or the shorthand
margin
property. The shorthand accepts values in this order:
One value: Sets all four sides equally
Two values: First value for top/bottom, second for left/right
Three values: First for top, second for left/right, third for bottom
Four values: Top, right, bottom, and left in sequence
Margins accept positive values (creating space), negative values (causing overlap), and units like pixels, percentages, or
auto
. Using
auto
for margins is a common technique to center block elements horizontally. Note that vertical margins between adjacent elements can collapse—when this happens, only the larger margin takes effect.

Padding

Padding is the space between an element's content and its border. Unlike margins which create space outside an element, padding creates space inside the element. You can control padding using individual properties (
padding-top
,
padding-right
,
padding-bottom
,
padding-left
) or the shorthand
padding
property.
The padding shorthand property follows the same pattern as margins:
One value sets padding equally on all sides
Two values set top/bottom and left/right padding
Three values set top, left/right, and bottom padding
Four values set top, right, bottom, and left padding in sequence
Unlike margins, padding values cannot be negative, and they don't collapse with other elements' padding.

Float

The
float
property positions elements to the left or right of their container, allowing text and inline elements to flow around them. Common values include:
left
: Positions the element to the left
right
: Positions the element to the right
none
: Keeps the element in normal flow (default)
While floats were traditionally used for page layouts, modern developers prefer Flexbox and Grid. However, floats remain useful for simple image alignment and small component positioning. Remember to specify a
width
when using
float
, or the element will expand to its container's full width.

Position

The
position
property determines how elements are placed on a web page. It accepts these values:
Static: The default position where elements follow the normal document flow.
Relative: Places an element relative to where it would normally appear, while maintaining its space in the document flow.
position: relative; top: 10px; left: 20px;
​
Absolute: Positions an element relative to its nearest positioned ancestor. If none exists, it positions relative to the
<html>
element.
Fixed: Positions an element relative to the viewport, keeping it in place during scrolling.
position: fixed; bottom: 0; right: 0;
​
Sticky: Combines relative and fixed positioning—the element switches between these modes based on scroll position.

Pseudo-Classes

Pseudo-classes style elements in specific states without using JavaScript. They're added to selectors using a colon (
:
). Here are the main types:
:link
: Styles unvisited links
:visited
: Styles visited links
:hover
: Styles elements on mouse hover
:focus
: Styles elements when focused
:active
: Styles elements during interaction

Let's Continue Modifying Our HTML Page

Now that we've covered the theory, let's connect our CSS file within the
<head>
tag to it:
<head> <meta charset="UTF-8"> <title>Finland</title> <link rel="stylesheet" type="text/css" href="style.css"> </head>
​
Modifying
<body>
element
Now we are modifying the document's body. The
<body>
element contains all the content of an HTML document, including headings, paragraphs, images, hyperlinks, tables, and lists, etc.
Here we set the font to Arial for the entire document, with sans-serif as a fallback option. Setting both margin and padding to 0 removes the browser's default spacing. The background color creates a light blue backdrop, while the text color is set to dark gray. The line-height property controls the spacing between lines of text.
body { font-family: Arial, sans-serif; margin: 0; padding: 0; background-color: #f0f8ff; color: #333; line-height: 1.6; }
​
Modifying
<h1>
tag
Let's look at how we modify the
<h1>
tag. We set its font size to 50px, change its color to deep blue, and center-align it on the page. The margin is set to 20px and 0—but what does this mean?
The value
20px 0
is a shorthand for specifying the top/bottom and left/right margins:
The first value (
20px
) applies to the top and bottom margins of the element.
The second value (
0
) applies to the left and right margins of the element.
To break this down:
Top margin:
20px
Bottom margin:
20px
Left margin:
0
Right margin:
0
h1 { font-size: 50px; color: #00509e; text-align: center; margin: 20px 0; }
​
Modifying Navigation Menu
<ul>
Setting
list-style
to
none
removes the default bullet points from the list. Setting both margin and padding to 0 eliminates the browser's default spacing. The
text-align
property centers the entire navigation menu, while the background color is set to navy blue.
ul { list-style: none; padding: 0; text-align: center; background-color: #004080; margin: 0; }
​
The display property arranges the
<li>
list items horizontally by making them inline-block elements. The margin property adds spacing between menu items—the first value of 0 sets top and bottom margins to zero, while the second value controls the right and left margins at 15px.
ul li { display: inline-block; margin: 0 15px; }
​
Here we modify the links within list items. The text-decoration property removes underlines from links, while the color is set to white. The font-weight property makes the text bold, and padding creates space around the link text.
ul li a { text-decoration: none; color: white; font-weight: bold; padding: 5px 10px; }
​
Here we've introduced the
:hover
pseudo-class, which applies styles when a user hovers their mouse over a link. In this case, it changes the background color to orange, sets the text color to navy blue, and adds rounded corners through border-radius.
ul li a:hover { background-color: #ffa500; color: #004080; border-radius: 5px; }
​
Now let's style our image. Since we've already set the width and height in HTML, we don't need to specify them in CSS. The display property makes the image a block-level element. The margin property centers the image horizontally with
auto
while adding vertical spacing
20px
. We've added a light gray border around the image and rounded its corners using border-radius.
img { display: block; margin: 20px auto; border: 5px solid #ddd; border-radius: 10px; }
​
For the
h2
heading, we set the color to navy blue and use margin-left to indent it slightly from the left edge.
h2 { color: #004080; margin-left: 20px; }
​
Let's modify the paragraph
<p>
tag. The margin property creates space around the paragraph, while padding adds inner spacing between the text and its container. The background color is set to light cyan, and a border-left property adds a blue vertical line to the left.
p { margin: 20px; padding: 10px; background-color: #e6f7ff; border-left: 5px solid #00509e; }
​
The
a:visited
selector changes the color of previously visited links to gray
a:visited { color: #888; }
​
The
a:active
selector styles links at the moment they are clicked
a:active { color: red; }
​
We must also consider responsive design for different screen sizes. @media (max-width: 600px) targets screens narrower than 600 pixels. The
h1
font-size property reduces the main header for better readability on mobile devices. The
ul li display
property arranges menu items vertically for easier navigation, while text-align and margin properties center each item with proper spacing.
@media (max-width: 600px) { h1 { font-size: 1.5em; /* Smaller font size for mobile */ } ul li { display: block; text-align: center; margin: 10px 0; } }
