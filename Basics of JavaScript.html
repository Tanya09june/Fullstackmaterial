Basics of JavaScript

Theory

Now that you've built a website with HTML and CSS, it's time to make it interactive using JavaScript! You can add features like dark mode, form validation, and fetching and displaying data from APIs.

What is JavaScript?

With JavaScript, you can build mobile apps, Front-end Web Development, Back-end Web Development, Game Development, and more. Since you're already familiar with programming concepts from the Python course, we'll focus on JavaScript's unique syntax, skipping the theoretical concepts you know. It will be more Python against JavaScript.
JavaScript is a versatile, high-level programming language that makes web pages interactive. Since its creation by Brendan Eich at Netscape in 1995, it has grown from a simple scripting language into one of the world's most widely used programming languages.
While HTML structures content and CSS styles it, JavaScript adds behavior and functionality to web pages. It enables developers to create dynamic content, validate forms, handle user interactions, and update pages without refreshing.
Today's JavaScript extends far beyond browsers—it powers servers (Node.js), mobile devices, desktop applications, and Internet of Things (IoT) devices. As a cornerstone of modern web development, it enjoys universal browser support and benefits from a rich ecosystem of libraries and frameworks.

How to run JavaScript?

There are multiple ways to run JavaScript code. Unlike Python, JavaScript cannot be run directly from the console without Node.js, which we'll cover in the Backend section. To run JavaScript in a browser, we need HTML. Here's how it works: in a browser, JavaScript runs within an HTML page and is executed by the browser's JavaScript engine. Alternatively, in the terminal, you can run JavaScript directly using Node.js, a runtime environment.
For now, we will implement JavaScript through an HTML page. Like CSS, there are three ways to include JavaScript in an HTML document: Inline JavaScript, Internal JavaScript, and External JavaScript file. We are going to use External JavaScript file.
The best practice is to store JavaScript in an external file and link it using the
<script>
tag with a
src
attribute. First, create both HTML and JavaScript files. Then, in the
head
tag, add the JavaScript.
<head> <meta charset="UTF-8"> <title>JavaScript testing</title> <script src="scripts.js" defer></script> </head>
​
The
defer
attribute in
<script>
downloads the script while the browser parses HTML, but executes it only after the page loads.

Variables

In JavaScript, variables can store numbers, strings, objects, arrays, and functions. Think of a variable as a container for information—you give it a name and assign it a value. It's best practice in JavaScript to declare variables before using them. When learning JavaScript, you'll encounter three types of variable declarations: var, let and const. But what's the difference between them?
First example: var
var name = "Othman"; console.log(name);
​
Using
var
is an outdated method. The
var
keyword was the standard in JavaScript code from 1995 to 2015.
Second example: let
let age = 30; console.log(age); //Output 30 age = 50 console.log(age); //Output 50
​
let
is used to declare variables whose values may change during program execution.
Third example: const
const adult = true; console.log(adult);
​
const
is used to declare variables whose values must remain unchanged throughout the program's execution.
There are a few rules for naming a variable:
It must start with a letter or an underscore.
It may contain letters, digits, and underscores in any combination.
It may not contain character spaces. As an alternative, use underscores in place of spaces, or close up the space and use camel case instead (for example, my_variable or myVariable).
It may not contain special characters (e.g., ! . , / \ + * =).
Rule of Thumb:
1. Always declare variables
2. Always use 
const
 if the value should not be changed
3. Always use 
const
 if the type should not be changed (Arrays and Objects)
4. Only use 
let
 if you can't use 
const
5. Only use 
var
 if you MUST support old browsers

Conditional statement (if)

In Python,
if
statements use indentation to define code blocks and rely on colons to separate conditions, while in JavaScript, curly braces
{}
are used to enclose the code blocks. For example, a Python
if
statement looks like this:
if condition: # code to execute if condition is true elif condition: # code to execute if condition is false else: # code to execute
​
Whereas in JavaScript, the equivalent would be:
if (condition) { // code to execute if condition is true } else if (condition) { // code to execute if condition is false } else { // code to execute }
​

Logical Operators

Logical operators in Python and JavaScript share similarities, but there are some key differences in syntax and behavior. In Python, logical operators include
and
,
or
, and
not

&&

||
for "or", and
!
for "not". For example:
# Python logical operators x = True y = False print(x and y) # False print(x or y) # True print(not x) # False
​
// JavaScript logical operators let x = true; let y = false; console.log(x && y); // false console.log(x || y); // true console.log(!x); // false
​
One significant difference is that Python uses its keywords for logical operations, making them more readable, while JavaScript relies on symbols, which may be less intuitive.

While Loop

In both Python and JavaScript, the
while
loop is used to execute a block of code repeatedly as long as a specified condition is
True
. However, their syntax differs slightly.
In Python:
count = 0 while count < 5: print(count) count += 1
​
Here, indentation is used to define the code block, and the
while
keyword is followed by the condition.
In JavaScript:
let count = 0; while (count < 5) { console.log(count); count++; }
​
JavaScript uses curly braces
{}
to define the code block, and the condition is enclosed in parentheses
()
after the
while
keyword.

Iterative Loops (for)

Python: Python's
for
loop is simple and intuitive. It iterates directly over elements of a list, range, or other iterable.
my_list = [1, 2, 3, 4] for item in my_list: print(item) # Outputs each item in the list
​
JavaScript: JavaScript offers multiple ways to iterate over arrays. The traditional
for
loop uses an index, but modern approaches like
for...of
and
forEach
are more concise:
let myArray = [1, 2, 3, 4]; for (let i = 0; i < myArray.length; i++) { console.log(myArray[i]); // Outputs each item in the array } // Using for...of for (let item of myArray) { console.log(item); // Outputs each item in the array }
​

Functions

Functions in Python and JavaScript are used to encapsulate a block of reusable code, but their syntax and some functionalities differ. In Python, functions are defined using the
def
keyword, followed by the function name and parameters in parentheses. Indentation is used to define the body of the function. For example:
def greet(name): return f"Hello, {name}!" print(greet("Alice")) # Output: Hello, Alice!
​
In JavaScript, functions can be declared using the
function
keyword, or more modern approaches like arrow functions (
=>
). For example:
function greet(name) { return `Hello, ${name}!`; } console.log(greet("Alice")); // Output: Hello, Alice! // Using arrow functions const greet = (name) => `Hello, ${name}!`; console.log(greet("Alice")); // Output: Hello, Alice!
​
One major difference is that Python enforces indentation for readability, while JavaScript uses curly braces
{}
to define the function body. Additionally, JavaScript functions can be assigned as values to variables (as seen with arrow functions), whereas Python primarily uses the
def
keyword for function declarations.
