Basics of DOM

Theory

We've learned HTML, CSS, and JavaScript—but what comes next? Will we only use JavaScript in the console and alert popups? Not at all! In today's lecture, we'll dive into the Document Object Model (DOM).

What is DOM?

The DOM provides a way to access and manipulate document contents. While we commonly use it with HTML, the DOM works with any XML language. Though we're focusing on its JavaScript implementation, the DOM can be accessed through other programming languages like PHP, Ruby, and C++.
The DOM represents an HTML document as a tree of objects. Each HTML element becomes a node in this tree, and JavaScript can access, modify, or delete these nodes.
Let's revisit the HTML tree diagram we saw in the CSS lecture.
The diagram above shows how the Document Object Model (DOM) represents HTML elements in a webpage as a tree structure. Here's what we can see:
The root element html sits at the top of the tree
Below it are two main branches: head and body
The head section has three child elements: title, style, and meta
The body section includes various elements such as h1, p (paragraphs), and h2 headings
Some elements contain nested elements (children), like paragraphs with em (emphasis) and img (image) elements

Accessing DOM Elements

The document object provides several methods for accessing and manipulating DOM elements. For example, when implementing a dark mode feature, we can:
Find the moon icon button using its ID
Listen for when the user clicks it
Change the page's background color to dark
Update the icon to show a sun instead
DOM methods allow developers to create rich interactive experiences. For instance, social media features might include a like counter that updates instantly when clicked or comment threads that expand and collapse. Form interactions can feature real-time password strength indicators and search bars with auto-complete suggestions as you type. Let's now explore these DOM methods in practice. There are several methods for accessing nodes in the document.

Element Name

document.getElementsByTagName("p");
​
This method selects any element or elements specified as an argument. In the code above, it returns every paragraph on the page in a collection called a nodeList, ordered from top to bottom in the document. NodeLists function similarly to arrays—you can access specific paragraphs within the nodeList using index numbers, just as you would with an array.
document.getElementsByTagName("p")[0].innerHTML = "Hello World!";
​
This code selects the first paragraph on our page and changes its text to "Hello World!"

Id Attribute Value

document.getElementById("recipe");
​
Similar to CSS, we can use unique HTML IDs to target specific elements. This method returns a single element by looking up its ID attribute value.

Class Attribute Value

document.getElementsByClassName("button");
​
Again similar to CSS, we can target multiple elements that share the same
class
attribute. Like
getElementsByTagName()
, this method returns a nodeList that we can access by index or iterate through.

Selector by ID

let title = document.querySelector("div > p"); title.textContent = "Changed Text!";
​
querySelector()
finds and returns the first element in the document that matches a specified CSS selector or group of selectors. In this code, we're selecting the first
<p>
element that is a direct child of a
<div>
element.

Selector by Multiple Elements

document.querySelectorAll(".sidebar p");
​
Similar to
querySelector()
, but this method selects all matching elements rather than just the first one.
querySelectorAll()
returns a nodeList, like
getElementsByTagName()
and
getElementsByClassName()
, even if the selector matches only a single element.

Accessing an attribute value

<img src="stratocaster.png" alt="electric guitar" id="lead-image">
​
const bigImage = document.getElementById("lead-image"); // Get the element alert(bigImage.getAttribute("src")); // Alerts "stratocaster.jpg"
​
The DOM allows you to access more than just elements. You can retrieve attribute values from element nodes by using
getAttribute()
with the attribute name as an argument. In this example, we first select the image with ID "lead-image", which has attributes like src, alt, and id as shown in the HTML code. Then, we retrieve the src attribute value, which creates an alert displaying "stratocaster.jpg".

Manipulating Nodes

Once we've accessed a node using one of the previously discussed methods, the DOM provides several built-in methods for manipulating those elements, their attributes, and their contents.

Setting an attribute value

bigImage.setAttribute("src", "piano.jpg");
​
To change the value of an src attribute to a new pathname for example, use
setAttribute()
. This method takes two arguments: the attribute you want to change and its new value.
Here we swapped out an image, but we could use
setAttribute()
to make many other changes throughout our document:
Update checkbox and radio button states based on user interactions
Change the stylesheet by updating the href value of the CSS link element
Modify title attributes to reflect element states (e.g., "This element is currently selected")

Setting or Getting the HTML content

const introDiv = document.getElementsByClassName("intro"); introDiv[0].innerHTML = "<p>This is our intro text</p>";
​
innerHTML
gives us a simple method for accessing and changing the text and markup inside an element.

Styling

document.getElementById("intro").style.color = "#fff"; document.getElementById("intro").style.backgroundColor = "#f58220";
​
Using the style property, the DOM lets you add, modify, or remove CSS styles from elements—similar to how inline style attributes work.
In JavaScript and the DOM, CSS property names that contain hyphens (like background-color and border-top-width) are written in camelCase (backgroundColor and borderTopWidth) to prevent the hyphen from being interpreted as a minus operator.

Adding and Removing Elements

The DOM enables developers to dynamically modify the document structure by adding or removing nodes.

Create a new element

// Create element: const para = document.createElement("p"); para.innerHTML = "This is a paragraph."; // Append to another element: document.getElementById("myDIV").appendChild(para);
​
To create a new element, use the
createElement()
method. This method takes a single argument: the type of element you want to create in this example
p
. One thing to note is that the new element won't appear on the page immediately after creation. Instead, it exists in JavaScript's memory until you explicitly add it to the document.
After creating a new element and text content, we need to add them to the document. This is where the
appendChild()
method comes in. It takes a single argument: the node you want to add to the DOM.

Inserts an element before another element

The
insertBefore()
method places an element before another element. It takes two arguments: the node to be inserted and the reference element that it should be placed in front of. The parent element that will contain both nodes must also be specified.
<div id="our-div"> <p id="our-paragraph">Our paragraph text</p> </div>
​
const ourDiv = document.getElementById("our-div"); const para = document.getElementById("our-paragraph"); const newHeading = document.createElement("h1"); const headingText = document.createTextNode("A new heading"); newHeading.appendChild( headingText ); // Add our new text node to the new heading ourDiv.insertBefore( newHeading, para );
​

Removing an element

You can remove a node or an entire branch from the document tree using the
removeChild()
method. This method takes a single argument: the node you want to remove. Like
appendChild()
, the
removeChild()
method must be called on the parent element of the node you want to remove.
<div id="parent"> <div id="remove-me"> <p>Hello World!</p> </div> </div>
​
const parentDiv = document.getElementById("parent"); const removeMe = document.getElementById("remove-me"); parentDiv.removeChild( removeMe );
​

Assignments

Objective:

Your task is to create a simple Bank Manager program that allows a user to manage their bank balance. The program should support deposits, withdrawals, balance inquiries, and exiting the application.

Instructions:

Initialize a balance at
0
.
Continuously prompt the user to choose an action until they decide to exit.
Available actions:
Deposit: Ask the user for an amount and add it to their balance.
Withdraw: Ask the user for an amount and subtract it from their balance (only if sufficient funds are available).
Check Balance: Display the current balance to the user.
Exit: Stop the program.

Requirements:

Use the
prompt
function to get user input.
Validate user input:
Deposits and withdrawals must be positive numbers.
The user cannot withdraw more than their current balance.
Display meaningful messages to the user after each action.
If an invalid action is entered, show an error message and prompt again.
The program should continue running until the user chooses to exit.

Example Interaction:

Choose an action: deposit, withdraw, check balance, exit > deposit Enter amount to deposit: > 100 Deposited 100. New balance: 100 Choose an action: deposit, withdraw, check balance, exit > withdraw Enter amount to withdraw: > 50 Withdrawn 50. New balance: 50 Choose an action: deposit, withdraw, check balance, exit > check balance Your balance is: 50 Choose an action: deposit, withdraw, check balance, exit > exit Thank you for using the Bank Manager!
